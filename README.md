# Open World Farming Simulation (UE5)

## Overview
Developed an open-world farming simulation focusing on scalable gameplay systems and real-time interactions.

The project explores system design in Unreal Engine, including environment simulation, gameplay logic, and performance optimization for large scenes.

## Tech Stack
- C++
- Unreal Engine 5
- Blueprint
- HISM (Hierarchical Instanced Static Mesh)

## My Contributions

- Designed and implemented a hybrid C++ and Blueprint architecture for flexible and maintainable gameplay systems

- Developed a plant system with time-based growth, state transitions, and harvesting mechanics

- Implemented a dynamic weather and seasonal system affecting terrain, foliage, and gameplay behavior

- Built a modular building system with placement and interaction logic

- Optimized large-scale environment performance using Hierarchical Instanced Static Meshes (HISM)

## Technical Highlights

- Scalable system design for open-world gameplay

- Integration of multiple systems (growth, weather, building) into a unified gameplay loop

- Performance optimization for large scenes using instancing techniques

- Clear separation of core logic (C++) and high-level control (Blueprint)
